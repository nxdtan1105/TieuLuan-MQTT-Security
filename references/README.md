## 1. MQTT Specification

- Tổ chức: OASIS
- Nội dung sử dụng:
  - Kiến trúc MQTT
  - Mô hình Publish/Subscribe
  - MQTT Client
  - MQTT Server/Broker
  - Topic và Message
  - Các vấn đề liên quan đến bảo mật

- Link:
  https://docs.oasis-open.org/mqtt/mqtt/v5.0/mqtt-v5.0.html
