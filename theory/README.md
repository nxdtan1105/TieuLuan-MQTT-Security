# Theory

Thư mục này chứa các nội dung lý thuyết phục vụ đề tài:

**Rủi ro khi MQTT không mã hóa**

## Nội dung

### 1. Kiến trúc MQTT

- Mô hình Publish/Subscribe
- MQTT Client
- MQTT Broker
- Topic và Message

### 2. Bảo mật MQTT

- Xác thực
- Phân quyền
- Mã hóa
- TLS

### 3. MQTT không mã hóa

- Kết nối MQTT qua TCP
- Truyền dữ liệu không được mã hóa
- Nguy cơ lộ thông tin trên đường truyền

### 4. MQTT sử dụng TLS

- Bảo vệ kênh truyền
- Xác thực máy chủ
- So sánh với MQTT không mã hóa
